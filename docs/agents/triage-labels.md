# Triage Labels

Пять ролей разбора задач сопоставлены стандартным меткам GitHub.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу нужно оценить |
| `needs-info` | `needs-info` | Нужна дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача описана и готова для агента |
| `ready-for-human` | `ready-for-human` | Требуется работа человека |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык называет роль, используй метку из второго столбца. Категории `bug` и
`enhancement` уже есть в репозитории и применяются отдельно от этих состояний.
