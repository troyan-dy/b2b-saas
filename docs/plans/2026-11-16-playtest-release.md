## Ограничения
- До кода задача заведена и назначена в GitHub; каждый коммит реализации указывает issue.
- 12 агентов, 3 стартовых места; обычная стройка/улучшение без отдельной денежной платы, с работой и зарплатой.
- API ускоряет строителей; инфраструктура остаётся платной.
- Исследования: два направления, реальные перемены, датированные отчёты и отсутствие пустой автотраты. Пользователь делегировал переработку интерфейса.
- Инфраструктура видна на поле, доступна помощь основателя и управление общей очередью.
- Не объявлять причину пользовательской остановки подтверждённой без его сохранения.
- Исследование/ревью только чтением возможно в основном checkout. Код и тесты — в назначенном worktree, чужие изменения не откатывать.
