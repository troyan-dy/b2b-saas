# B2B SaaS

## Первый стартап

**Первая подписка** — момент, когда компания впервые получает выручку от клиентов. Приход первого клиента сам по себе ещё не означает подписку: продукт должен уметь принимать оплату.

**Чистый поток** — сколько денег в секунду компания получает или теряет с учётом расходов. Даже после первой подписки чистый поток может оставаться отрицательным.

**Прибыльный релиз** — релиз, на момент которого чистый поток компании строго положителен. Положительный остаток на счету или разовая выплата сами по себе не делают релиз прибыльным.
