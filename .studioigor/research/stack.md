# Stack — research (2026-11-14)

Игра: 2D тайкун забегами в браузере на ПК. Чертёж в изометрии с отъездом камеры по трём этапам,
сотни летящих квадратов, тёмный терминал, правая панель, диалоги и новости обычным текстом.
Стиль зафиксирован: «Терминал и чертёж» из Yes-Driven Development (YDD), уже сделанный на
Phaser 4 + TypeScript + Vite с HTML-слоем.

## Findings
- За основу взято вчерашнее исследование для YDD (clicker-game/.studioigor/research/stack.md,
  2026-11-13); ниже — что перепроверено сегодня по реестру npm.
- Phaser: последний релиз по-прежнему 4.2.1 (опубликован 2026-07-09), новых версий нет.
- PixiJS: 8.23.0 (2026-11-11) — вчера в источниках была 8.20.1; только рендер, сцены, твины,
  ввод и звук собираются самим.
- Vite 8.3.8, Vitest 5.1.0, Playwright 1.65.1, ESLint 10.15.0 — те же линии, что в YDD.
- TypeScript: latest уже 7.0.2, но typescript-eslint 8.72.2 требует `>=4.8.4 <6.1.0` —
  закреплять TypeScript 6.0.x, как в YDD.
- Node 24.22.1 и npm 11.19.1 на машине есть.
- В YDD на этом стеке измерено: 277 кадров/с в среднем на экране со всеми покупками, память
  19 МБ, сборка 4,5 МБ — бюджеты веба выполняются с большим запасом.
- В YDD готово и переносится: палитра (`src/data/palette.ts`), стили терминала и панели
  (`src/ui/style.css`, `src/ui/terminal`, `src/ui/card`), чертёж и узлы (`src/view/blueprintView.ts`,
  `nodeTextures.ts`), квадраты (`src/view/squares.ts`), съёмка кадров (`tools/capture.mjs`),
  панель тюнинга, звук ZzFX, RNG с сидом, сохранение. Весь этот код привязан к Phaser 4.
- Тайкун — жанр, где много интерфейса: раздача агентов, карточки рынка, диалоги. В YDD это
  решено HTML-слоем поверх канваса, и это остаётся верным для любого из кандидатов.

## What this changes
- Unity, Unreal, Godot отпадают по тем же причинам, что в YDD: только браузер, 2D, маленькая игра.
- Phaser 4.2.1 — основной кандидат: стиль уже реализован именно на нём, перенос кода даёт
  первую сцену в стиле за часы, а не дни.
- PixiJS 8 и чистый DOM/SVG возможны, но чертёж, квадраты и камеру пришлось бы писать заново;
  выигрыша для этой игры нет: производительность и размер сборки у Phaser не узкое место.
- Риск Phaser прежний: модель помнит API Phaser 3 — сверяться с `node_modules/phaser/types` и
  документацией в пакете (принятое улучшение P-20261113-01).
