| Git LFS | Pages не подставляет файлы LFS: ветка со сборкой собирается в отдельном временном репозитории без `.gitattributes` |

| внешние запросы | в сборке нет: шрифты, музыка и картинки лежат рядом |
| что становится публичным | сайт с игрой — всегда; исходники и журнал студии — только если отправить ветку `master`; в её коммитах стоит почта автора |
| откат | удалить ветку `gh-pages` или выключить Pages в настройках репозитория |

## Что это меняет в плане
- публикуем готовую сборку веткой `gh-pages` через `tools/publish.py`, без Actions
- автор коммита в публичной ветке — адрес `noreply` GitHub, чтобы не светить почту
- отправлять ли `master` (исходники, `.studioigor/`, почта в коммитах) — отдельное решение пользователя
